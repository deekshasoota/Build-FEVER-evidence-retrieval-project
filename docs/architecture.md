# Architecture

Claims and wiki sentences enter through JSONL readers. Wiki pages are flattened without losing page title or sentence ID. Preprocessing applies Unicode NFKC normalization, case folding, tokenization, optional stop-word removal and optional Porter stemming; index metadata records the selected settings. `InvertedIndex` stores evidence metadata, per-document token counts and term postings; it serializes to JSON for reload. SQLite FTS stores display text separately from preprocessed terms.

Retrievers: Boolean set operations, corpus-wide TF-IDF/cosine, BM25, MiniLM sentence embeddings, and reciprocal-rank fusion of the three ranked methods. The evaluation runner scores the four ranking methods and groups results by available domain labels. The pipeline returns actual evidence with source metadata and makes a deliberately conservative NOT ENOUGH INFO decision because no evidence-pair verifier is trained. Streamlit loads a saved index and presents evidence and the limitations.
